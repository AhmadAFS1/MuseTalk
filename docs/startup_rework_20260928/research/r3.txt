Intended boot contract (docs, checked against code):
- Vast template supplies MUSETALK_AWS_SECRET_ID plus a bootstrap AWS key that can only read the secret. scripts/bootstrap_aws_secrets.py then exports the runtime S3 key, AVATAR_S3_*, TTS/IDLE/UPLOAD buckets and LINGUA_* control-plane vars. The server then registers with the control plane, and /health waits on ready_for_health().

Why a fresh non-3090 box fails to boot today:
- The artifact key is hard-coded to rtx3090 (vast_onstart.sh:37).
- On the 4070S, the downloaded engines failed with "expecting compute 8.9 got compute 8.6" and "No compatible device was found" (PROVEN, benchmarks/same-avatar/REPORT.md:26-33).
- The selector and the UNet meta have no GPU or arch check.
- With no S3 access the boot also dies: restore=required with no URI stops at vast_onstart.sh:690; the selector exits 1 on a clean repo (dry-run into scratch: exit=1) and vast_onstart.sh:669 dies.
- models/ and calibration/ are gitignored, so a fresh clone has neither engines nor calibration.
- TAESD weights (models/taesd) are not fetched by download_weights.sh or checked by setup_complete. Without them, vae_fast_decoder.py:117-124 downloads madebyollin/taesd from Hugging Face at runtime.
