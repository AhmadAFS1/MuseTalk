Its GPU-quiet precondition also fails whenever another server is up.
    Host RAM: loading the shipping 2.2 GB .ts spikes VmHWM to 9.5 GB (min MemAvailable 3.7-4.2 GB from 12.4 GB). The box currently shows about 9 GB available with the server up, so a restart that overlaps the old process, or a second server, risks OOM. Plan 0.1 asks for at least 14 GB MemAvailable before a server start.
    The shipping .ts G-UNET margin is thin: max_abs_max 0.4016 against a 0.5 gate (japanese_realtime_talking_7d94520b7f). Rebuilt per-arch .ts engines on other GPUs may not pass the same gate.
